项目简介

场景聚焦与商业落地：结合市场竞争与资源约束，将产品聚焦为企业销售场景的 Revenue Intelligence，明确不做通用办公、传统 CRM、通用 Agent 与门店督导。围绕 Capture—Insight—Act 打通销售事实采集、客户洞察与行动转化，重点构建客户真相图谱，关联决策人、议题、竞品、承诺与风险，推动制造、汽车、金融等行业完成客户验证与订单转化，年销售额超百万元。

负责场景定位、产品 Roadmap、企业权限与交付边界，协同销售、解决方案及研发推进客户验证。

产品解决路径

01多源采集与授权上下文

围绕 Capture—Insight—Action 制定 Roadmap，规划连接录音卡、腾讯／钉钉会议、CRM 与日程待办，将客户、商机、会议与会话、任务、工作产物关联；按成员身份、业务范围及资料权限组织沟通原话、行业知识与历史行动，支撑持续追问和任务接续。

02销售洞察、客户真相图谱与经验复制

规划通过 MCP 接入业务工具，以行业 Skills 承载销售方法与分析规则，支持多维 Ask、拜访准备、话术质检、商机阻塞分析及优秀案例提炼；围绕决策人、议题、竞品、承诺和风险构建客户真相图谱，将原始记录转化为可跟进的建议、可复用的案例与销售方法。

03IM 入口与主动任务

负责 Bot 接入钉钉、飞书、企业微信，支持业务 Ask 与自然语言创建定时任务；用户确认执行时间、周期、接收人与输出要求后，按计划生成并推送销售报告、会议总结和行业信息跟踪结果，推动销售智能进入日常工作流。

04企业权限与交付治理

负责设计个人／团队／企业分层，明确数据可见、资源共享、Agent 工具调用与操作审批边界；规划席位、Credits 及订阅升级规则，界定标准产品与客户定制范围，协同销售、解决方案与研发推进客户验证和差异化交付。

05团队协作桌面 Agent

围绕会话、任务与工作产物，探索将百销的销售洞察延伸为可执行的企业 AI 工作流。通过多引擎桌面 Agent 承接资料分析、内容生成与交付任务，支持授权上下文、任务接力和成果回流，让销售智能从“给出建议”进入“完成任务”，并验证个人 Agent 向团队协作工作区的延伸。
